Get a server

FreeRDP Web connects to any RDP server: xrdp, gnome-remote-desktop, or Windows' own Remote Desktop. The packages below are the release kit's xrdp, with Wayland sessions (GNOME, KDE Plasma, sway), tested with this page before each release.

The packages for your Linux distribution, and native clients for your computer: the release kit's latest release.

Then connect

Keep the RDP server on 127.0.0.1 and reach it through SSH: Safety and tunnels has the one-line command. Then open FreeRDP Web and connect with your user name and password on the server.
