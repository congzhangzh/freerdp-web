Get a client

Three ways to reach your RDP server. Most people need only the first; the other two connect without a gateway.

1. In this browser

Nothing to install: open FreeRDP Web and connect. A web page cannot open a TCP connection itself, so it goes through a small WebSocket gateway next to the RDP server; Safety and tunnels has the one-line command, through SSH.

2. As a Chrome app

Chrome and Edge can install this page as an Isolated Web App, which connects to the RDP server directly, with no gateway. Today that takes two Chrome flags and developer mode, so you probably don't need it. If you do, the steps are on Install as app.

3. A native client

FreeRDP's own client for Windows, macOS and Linux, built by the release kit, with freerdp-tk, a window that keeps your connections. Any other RDP client works too, Windows' own Remote Desktop Connection included.
